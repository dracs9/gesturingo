# Проверка SignBridge

Дата: 29 сентября 2026. Ветка: `codex/signbridge-frontend`.

## Автоматические проверки

- TypeScript: проверка типов проходит.
- Vite: production-сборка проходит, результат в `dist/`.
- Vitest: **26 тестов в пяти файлах**.
- Prettier: форматирование проекта проверено.

Сценарии выполняются в jsdom и не заменяют тест настоящей камеры/браузера.

| Область            | Что проверено                                                                                                                                                              |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Сценарий общения   | Ошибка → красный скелет и стрелка → исправление → зелёный скелет → фраза в диалоге → ответ → итоги                                                                         |
| Неоднозначный жест | Стрелка скрывается, фраза не отправляется                                                                                                                                  |
| Словарь            | Поиск, маркировка непроверенных карточек, закрытие по Escape с возвратом фокуса                                                                                            |
| Камера             | Отказ в доступе, возможность текстового общения, выбор задней камеры без аудио, остановка при скрытии вкладки, освобождение позднего потока, ошибка/отмена воспроизведения |
| Интеграция         | Один eventId не создаёт повторных сообщений; адаптер и камера останавливаются при выходе с экрана; поздние результаты не принимаются                                       |
| Качество входа     | Низкая уверенность, конкурирующие/неизвестные классы, неверифицированный класс, незавершённое подтверждение, неверные координаты/суставы                                   |
| Отображение        | Вторая кисть, зеркальный просмотр и совпадение координат с видео другого соотношения сторон                                                                                |
| Хранение           | История не сохраняется без выбора пользователя; после включения восстанавливается; очистка требует подтверждения                                                           |
| Озвучивание        | Локальный русский голос предпочитается; устаревшие callbacks не меняют состояние; текст остаётся доступным без TTS                                                         |
| Субтитры           | Микрофон не запускается до согласия; результат не дублируется; отказ/повторный запуск/остановка освобождают ресурсы; TTS останавливает микрофон                            |

Модели Slovo/Bukva не подключены. Тест адаптера использует искусственные события и не доказывает качество распознавания РЖЯ.

## Ручная проверка перед демонстрацией

Визуальная проверка в настоящем браузере не выполнена: инструмент предпросмотра заблокирован административной проверкой доступа к локальному адресу. Обход блокировки не выполнялся. Поэтому реальная камера, голос, микрофон и внешний вид на устройствах пока не подтверждены.

1. Открыть сайт по HTTPS или localhost, пройти полный демонстрационный сценарий и отправить текст с обеих сторон диалога.
2. Проверить ширины 1440, 768, 390 и 320 px, переносы, прокрутку диалога, мобильное меню и экранную клавиатуру.
3. Проверить настоящую камеру: разрешение/отказ, включение/выключение, уход с экрана общения и скрытие вкладки. На телефоне проверить обе камеры.
4. Проверить русские голоса, повторное озвучивание, отмену и отсутствие TTS в неподдерживаемом браузере.
5. Включить субтитры только после согласия, проверить микрофон/отказ/остановку, убедиться, что собственная озвучка не попадает в диалог.
6. Проверить Tab/Shift+Tab, Escape, возврат фокуса, reduced motion и контраст подсказок.
7. Проверить сохранение/очистку истории и экспорт TXT на телефоне и компьютере.

## Проверка следующего этапа

После подключения реальной модели отдельно проверить минимум три документированных жеста, правильные и ошибочные исполнения разных людей, неизвестные жесты, повторения, временную последовательность, скорость на телефоне и управление без мыши/клавиатуры. Камеру и распознавание нельзя оценивать по демо-панели.
