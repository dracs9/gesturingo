# Gesturingo — режим «Разговор»: жесты ↔ речь

> Техническое задание на расширение проекта Gesturingo. Основное ТЗ — `CLAUDE.md`, все его
> правила (стек, без бэкенда, не придумывать формы жестов, работа по фазам, коммиты) действуют
> и здесь. Положи этот файл в `docs/TRANSLATOR_SPEC.md` и читай перед каждой задачей по переводчику.
> Работай строго по фазам (раздел 12). После каждой фазы — отчёт и СТОП.

---

## 1. Что добавляем

Сейчас Gesturingo учит дактилю, а «Мост» лишь собирает слово из букв и озвучивает его.
Добавляем полноценный режим **«Разговор»** — двусторонний канал между человеком, который
говорит жестами, и слышащим собеседником:

1. **Жест → текст → голос.** Пользователь показывает буквы дактиля или жесты-фразы,
   приложение собирает сообщение и озвучивает его через TTS.
2. **Речь → субтитры.** Слышащий собеседник говорит в микрофон, на экране появляется
   крупный текст.
3. **Лента диалога.** Обе стороны видят историю разговора.
4. **Режим «ошибка» для переводчика:** при неуверенном распознавании приложение не пишет
   «не распознано», а предлагает самый похожий известный жест, объясняет, что поправить,
   и НЕ озвучивает ничего, пока не уверено.

Главная демо-петля:
жест → скелет → распознавание → подтверждение → фраза → TTS → намеренная ошибка →
красный скелет + стрелка + инструкция → исправление → зелёный скелет → фраза →
слышащий отвечает голосом → субтитры на экране.

Честная рамка (показывается в интерфейсе и README): это не универсальный переводчик,
а ограниченный проверенный словарь русского жестового языка + полный дактиль.

## 2. Источники сообщений

| Источник | Что это | Приоритет |
|---|---|---|
| Дактиль | Слово по буквам (уже распознаём), автодополнение по словарю | P0 |
| Статичные жесты-фразы | 4–6 фраз, у которых жест — поза без движения | P1 |
| Динамические жесты-фразы | 3–5 частых фраз с движением, сравнение траекторий (DTW) | P2 |
| Нейросетевой классификатор последовательностей (TF.js) | Замена/дополнение DTW | Этап финала, не до сдачи |

**Не придумывай жесты.** Жесты-фразы берутся только из датасета Slovo (ai-forever)
по его меткам, эталоны строятся из данных, каждой фразе ставится `verified: false`
до сверки командой со словарём РЖЯ.

## 3. Экран «Разговор» (`/talk`)

### 3.1 Раскладка
- **Ноутбук:** слева камера (~55%) со скелетом, справа лента диалога и панель текущего
  сообщения.
- **Телефон (вертикально):** сверху камера, под ней текущее сообщение, ниже лента.
- Кнопка «Повернуть к собеседнику» (P2): полноэкранный крупный текст последней фразы
  жестующего — показать телефон слышащему.

### 3.2 Элементы
- **Статус руки** (как везде): «Руки не видно» / «Вижу руку» / «Распознаю…».
- **Строка набора:** буквы появляются по мере распознавания, курсор мигает.
- **Подсказки автодополнения:** до 3 слов из словаря, начинающихся с набранного.
- **Карточка кандидата:** распознанный жест-фраза или слово + уверенность + кольцо
  подтверждения (см. 4.3).
- **Лента диалога:** пузыри слева — жестующий (с иконкой руки), справа — слышащий
  (с иконкой микрофона). Крупный шрифт (≥ 20 px на телефоне), высокий контраст.
- **Строка микрофона** для слышащего собеседника: микрофон слушает сам, строка показывает
  статус («Слушаю собеседника» / пауза во время озвучки / ошибка с кнопкой «Включить микрофон»).
- **Справка «Как пользоваться»** (иконка «?») и **настройки** (шестерёнка) — справа сверху;
  подробные жесты-команды (раздел 5), дисклеймер и приватность — в справке, не на экране.

### 3.3 Точки входа
- Кнопка «Разговор» на карте уроков и на экране приветствия (после обучения управлению).
- Из урока: «Попробовать в разговоре» — открывает `/talk`.
- Из ленты: нажатие на фразу (курсором-пальцем) → «Как показать этот жест» → урок/карточка.

## 4. Канал «Жест → текст → голос»

### 4.1 Дактиль в разговоре
- Отличие от урока: ожидаемой буквы нет. Классификация идёт по всем статичным буквам:
  правила + kNN. Буква принимается, если:
  - top-1 kNN проходит правила своей буквы,
  - отрыв top-1 от top-2 по расстоянию ≥ порога,
  - состояние держится ≥ 0,6 с (голосование большинства по кадрам).
- **Двойные буквы:** та же буква добавляется повторно только после «сброса» — рука
  опустилась/поменяла форму или прошло 0,8 с с нейтральной позой.
- **Пробел / конец слова:** пауза без руки ≥ 1,2 с ИЛИ жест-команда «пробел» (раздел 5).
- **Автодополнение:** словарь `src/data/dictionary.ru.ts` (~2–5 тыс. частых слов,
  плюс все слова из `words.ts`). Выбор подсказки — жест-команда «выбрать» или курсор.
- **Удалить букву** — жест-команда (раздел 5).

### 4.2 Жесты-фразы
- Каждая фраза описывается `PhraseSpec`:
```ts
interface PhraseSpec {
  id: string;                 // "thanks"
  text: string;               // "Спасибо"
  kind: "static" | "dynamic";
  verified: boolean;
  source: { dataset: "slovo"; label: string; samples: number };
  // static: как у букв — состояния пальцев, ориентация, эталон-поза
  handshape?: LetterSpecLike;
  // dynamic: эталонные траектории (нормализованные), допуски
  templates?: Array<{ frames: number[][]; durationMs: number }>;
  tolerance?: { dtw: number; durationMin: number; durationMax: number };
  confusedWith?: string[];
}
```
- **Статичные фразы:** та же логика, что для букв (правила + kNN), удержание ≥ 0,8 с.
- **Динамические фразы (P2):**
  - кольцевой буфер последних ~1,5 с нормализованных точек (`sequenceBuffer.ts`);
  - сегментация: начало — рука вошла в кадр/скорость выросла выше порога;
    конец — скорость упала ниже порога на ≥ 200 мс;
  - признаки кадра: нормализованные точки + положение запястья относительно кадра
    (калибровка, 4.5) + скорость;
  - сравнение с шаблонами через DTW с окном Сакоэ–Чибы; решение — лучший шаблон,
    если расстояние < порога и отрыв от второго достаточен;
  - после успешного срабатывания — cooldown 1,5 с, чтобы фраза не добавлялась дважды.

### 4.3 Подтверждение перед озвучкой (защита от неверной речи)
Ошибочно произнесённая фраза хуже, чем непроизнесённая. Поэтому:
- Распознанное слово/фраза показывается в карточке кандидата с **кольцом 1,5 с**.
- Если за это время не было жеста «отмена» — фраза уходит в ленту и озвучивается.
- Жест «отмена» (раздел 5) — кандидат сбрасывается, ничего не озвучивается.
- Для слов по буквам: озвучка по жесту «сказать» или после паузы конца фразы ≥ 2 с.
- Настройка «Озвучивать сразу» (без подтверждения) — выключена по умолчанию.

### 4.4 TTS (`src/tts/`)
- Web Speech API `speechSynthesis`, язык `ru-RU`.
- Голоса загружаются асинхронно: ждать событие `voiceschanged`, выбирать лучший `ru-RU`
  голос (предпочтительно локальный), запоминать выбор в localStorage.
- **iOS/Safari:** озвучка разрешена только после действия пользователя. На кнопке
  «Включить камеру» проиграть пустую/тихую реплику, чтобы «разблокировать» синтез.
- Длинный текст дробить на предложения (в Chrome длинные реплики обрываются).
- Очередь реплик: новая фраза ставится в очередь, не перебивает текущую.
- Настройки: скорость (0,8–1,3), громкость, выбор голоса, «выключить звук».
- Если голоса `ru-RU` нет или API недоступен — фраза всё равно появляется в ленте,
  рядом значок «озвучка недоступна» с подсказкой (другой браузер/устройство).
- Во время озвучки на пузыре — анимация «говорит».

### 4.5 Калибровка для разговора (P1)
- 5–10 с: «Покажи открытую ладонь на уровне груди» → запоминаем центр и размер ладони
  в кадре. Нужна для подсказок положения («подними руку выше») и динамических фраз.
- Если калибровки нет — подсказки положения отключены, остальное работает.

## 5. Жесты-команды в разговоре

На этом экране руки заняты жестовым языком, поэтому курсор-палец и щипок ОТКЛЮЧЕНЫ
(иначе буквы будут срабатывать как клики). Команды — через **зоны-кнопки по краям кадра**:
пространство для жестов — центр кадра, зоны команд — верхние углы и верхний край.

| Команда | Как вызвать | Действие |
|---|---|---|
| Сказать | Рука в зоне «Сказать» (правый верхний угол) 0,8 с | Озвучить набранное |
| Удалить | Рука в зоне «⌫» (левый верхний угол) 0,8 с | Удалить последнюю букву/слово |
| Пробел / выбрать подсказку | Рука в зоне подсказки (верхний край) 0,8 с | Вставить слово |
| Отмена кандидата | Открытая ладонь к камере 1,2 с | Сбросить кандидата |
| Выход | Открытая ладонь 2 с | Вернуться на карту |

- Зоны рисуются полупрозрачно поверх видео, при наведении заполняется кольцо.
- Зона срабатывает, только если туда вошло запястье (точка 0), а не кончик пальца.
- Для слышащего собеседника доступны обычные касания/клик (справка, настройки, повтор микрофона):
  ограничение «без мыши» относится к пользователю жестового языка.

## 6. Канал «Речь → субтитры» (`src/stt/`)

- Web Speech API `SpeechRecognition` / `webkitSpeechRecognition`, `lang = "ru-RU"`,
  `interimResults = true`.
- **Слушает автоматически:** распознавание включается при входе на экран (`continuous`),
  каждая законченная фраза уходит в ленту, промежуточный текст — серым в субтитрах. Сессию,
  которую браузер закрыл (тишина, таймаут), приложение открывает снова. Нет разрешения,
  микрофона или сети — статус ошибки и кнопка «Включить микрофон» (iOS может требовать касание);
  частые сбои подряд останавливают перезапуски.
- **Эхо:** пока идёт TTS, распознавание речи приостановлено — иначе приложение запишет
  собственный голос как реплику собеседника.
- Субтитры крупным шрифтом дублируются поверх нижней части видео на 5 с, чтобы жестующему
  не нужно было переводить взгляд на ленту.
- **Поддержка браузеров:** Chrome/Edge — да; Safari — частично; Firefox — нет.
  Если API нет — строка микрофона заменяется полем ввода текста для слышащего
  с пояснением «Распознавание речи недоступно в этом браузере».
- **Приватность — честно:** в Chrome распознавание речи может обрабатываться на серверах
  браузера. В интерфейсе и README: «Видео с камеры не покидает устройство. Голос
  собеседника распознаётся средствами браузера и может обрабатываться его сервисом».
- Обработка ошибок: нет разрешения на микрофон, нет сети, тишина — понятные сообщения.

## 7. Режим «ошибка» в переводчике

Здесь пользователь — носитель жестового языка, поэтому подсказки — не «ты ошибся»,
а «камера не уверена, помоги ей». Формулировки нейтральные.

### 7.1 Логика решения
1. Ранжируем все известные классы (буквы и фразы) по расстоянию.
2. **Принято** (зелёный скелет): top-1 проходит правила/допуски и отрыв от top-2 достаточен.
3. **Почти** (красный скелет): top-1 близок, но нарушено одно-два условия → показываем
   самое существенное отклонение и инструкцию. Ничего не озвучиваем.
4. **Неоднозначно:** top-1 и top-2 близки → карточка «Вы имели в виду: А или Б?»
   с ключевым отличием («у Б большой палец прижат»); выбор — зонами-командами.
5. **Нейтрально** (серый): данных мало — руки нет, рука обрезана, движение не закончилось.

### 7.2 Типы подсказок и визуализация
| Что не так | Как определяем | Как показываем |
|---|---|---|
| Форма пальца | состояние/угол вне правила | подсветка пальца + текст («Согни безымянный») |
| Ориентация ладони | нормаль ладони не совпадает | дуговая стрелка поворота |
| Положение (после калибровки) | центр кисти вне целевой зоны | стрелка к пунктирной целевой зоне |
| Удержание | поза держалась меньше порога | кольцо + «Задержи на 0,5 с» |
| Направление движения (P2) | вектор движения не совпадает с шаблоном | призрачная траектория + стрелка |
| Скорость (P2) | длительность вне допуска | «Чуть медленнее» / «Чуть быстрее» |
| Похоже на другой жест | малый отрыв top-1/top-2 | карточка «Почти. Попробуйте…» с отличием |

Правила показа подсказок — как в основном ТЗ: одна за раз, после 0,7 с устойчивой ошибки,
смена не чаще раза в 1 с. Каждая подсказка пишется в статистику сессии.

Положение формулируется относительными словами («чуть выше», «ближе к центру»), без
обещания сантиметров.

## 8. Итоги разговора (P1)

После выхода из `/talk` — экран «Сводка»: сколько сообщений отправлено жестами и голосом,
сколько было подсказок и исправлений, какие жесты чаще требовали исправления
+ кнопка «Потренировать эти жесты» → урок с ними. В localStorage — только агрегированная
статистика и (по желанию, P2) история диалога с кнопкой «Очистить».

## 9. Данные для жестов-фраз (Slovo)

- Slovo (ai-forever) содержит готовые точки MediaPipe для видео. Скачай файл с точками
  (не видео), положи в `scripts/data/raw/slovo/` (в `.gitignore`).
- **Сначала разведка:** изучи формат файла точек и аннотаций, выведи структуру и пример.
- Скрипт `scripts/find-phrases.ts`: по списку кандидатов команды
  (`scripts/phrase-candidates.txt`, например: привет, спасибо, да, нет, помогите,
  пожалуйста, хорошо, извините, не понимаю, повторите) найти метки в аннотациях, вывести:
  метка → число видео → число исполнителей → доля кадров с найденной рукой →
  сколько рук участвует → оценка «статичный/динамический» (по разбросу положения
  запястья и формы кисти во времени).
- **Отбор для MVP:** только жесты одной рукой, с найденной рукой в ≥ 80% кадров.
  Жесты двумя руками и с опорой на лицо/тело — в роадмап.
- Скрипт `scripts/build-phrases.ts` (импортирует те же `normalize.ts`/`features.ts`):
  - статичные: медоид позы + статистика пальцев → черновик правил (порог 80%, как для букв);
  - динамические: обрезка по сегментации, ресемплинг до фиксированной длины, 3–5 шаблонов
    на фразу (медоиды по DTW от разных исполнителей), допуски по распределению DTW
    внутри класса;
  - матрица путаницы leave-one-signer-out → `confusedWith` и отчёт по точности;
  - выход: `src/data/phrases.generated.ts` + `phrases.overrides.ts` для ручных правок.
- Проверка команды: страница `/letters` расширяется вкладкой «Фразы» — эталон, анимация
  шаблона траектории, правила, точность, отметка `verified`.
- README: Slovo — источник, авторы, лицензия, что взяты только точки нужных классов.

## 10. Архитектура (новые и изменённые модули)

```
src/
  recognition/
    sequence/
      sequenceBuffer.ts     # кольцевой буфер кадров, сегментация по скорости
      dtw.ts                # DTW с окном Сакоэ–Чибы, чистый TS + тесты
      phraseMatcher.ts      # сравнение с шаблонами, отрыв, cooldown
    open/
      openClassifier.ts     # классификация без ожидаемой цели: ранжирование всех классов
      decision.ts           # accept / almost / ambiguous / neutral
    errors/
      translatorHints.ts    # формулировки и визуальные типы подсказок для переводчика
    control/
      commandZones.ts       # зоны-команды по краям кадра
  talk/
    composer.ts             # набор: буквы → слова → фраза, пробелы, двойные буквы
    autocomplete.ts         # префиксное дополнение по словарю
    conversationStore.ts    # лента диалога (zustand)
  tts/
    tts.ts                  # очередь, выбор голоса, разблокировка iOS, дробление
  stt/
    stt.ts                  # SpeechRecognition, автопрослушивание, пауза во время TTS
  screens/
    Talk.tsx, TalkSummary.tsx
  components/
    ConversationFeed, MessageBubble, ComposerBar, CandidateCard, CommandZones,
    CorrectionArrow, TargetZone, MicButton, SpeakingIndicator
  data/
    dictionary.ru.ts, phrases.generated.ts, phrases.overrides.ts
```

Правила производительности: распознавание по-прежнему в `requestAnimationFrame`,
в React уходят только события (буква принята, кандидат, подтверждено, реплика).
Буфер последовательности — типизированные массивы, без аллокаций в каждом кадре.
Бэкенда по-прежнему нет.

## 11. Нефункциональные требования

- FPS не ниже основного ТЗ (≥ 20 ноутбук / ≥ 12 телефон) с включённым буфером и DTW.
- От принятия фразы до начала озвучки < 500 мс (не считая кольца подтверждения).
- Экран работает без микрофона и без TTS — деградирует до текста, но не ломается.
- Все тексты — в `strings.ru.ts`.
- `?debug=1` на `/talk`: top-3 кандидата с расстояниями, состояние сегментации,
