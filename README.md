# Gesturingo — учись жестам и говори жестами

Веб-приложение, которым полностью управляют руками через обычную веб-камеру. За полминуты человек
учится навигации жестами, затем осваивает буквы русской дактильной азбуки. Камера замечает ошибку
и говорит, что поправить: «Согни безымянный палец». Выученные буквы сразу складываются в слова
в режиме «Тренажёр»: жесты превращаются в текст и голос.

Проект для ADMIT Hackathon 2026, кейс «Motion: камера вместо джойстика».

**Демо:** https://gesturingo.vercel.app/

---

## 1. Как запустить

Нужен Node.js 20.19+ или 22.13+.

```bash
npm install
npm run dev      # http://localhost:5173 — камера работает на localhost без HTTPS
npm test         # юнит-тесты распознавания (Vitest)
npm run lint     # ESLint
npm run build    # production-сборка в dist/
```

Деплой — Vercel (`vercel.json` уже настроен: SPA-роутинг, разрешение камеры). Бэкенда нет.

## 2. Как пользоваться

Мышь нужна один раз — нажать «Включить камеру». Дальше весь сценарий проходится руками.

| Жест | Как показать | Что делает |
|---|---|---|
| ☝️ Курсор | указательный палец | курсор на экране следует за кончиком пальца |
| 🤏 Щипок | соединить кончики большого и указательного | нажать кнопку под курсором |
| ⏳ Задержка | держать курсор на кнопке 1 с | нажать (запасной способ, если щипок не выходит) |
| 👍 Большой палец вверх | 0,8 с | «ОК» / дальше |
| ✋ Открытая ладонь к камере | 1,5 с, рука неподвижна | назад / выйти из урока |
| ↕️ Курсор у верхнего/нижнего края | — | прокрутить длинную страницу |

Какие жесты работают, зависит от экрана: в уроке и «Тренажёре» курсора нет, чтобы буква случайно
не нажала кнопку. Легенда в углу всегда показывает, какие жесты сейчас включены.

**Сценарий:** приветствие → обучение управлению (4 шага: курсор, щипок, палец вверх, ладонь) →
карта уроков → урок (3 буквы) → итоги (звёзды, точность, частые ошибки) → «Тренажёр» (слово из
выученных букв произносится вслух).

**Режим отладки:** добавь `?debug=1` к адресу. Показывает FPS, углы пальцев, состояние щипка,
позы, решение по букве и топ-3 kNN.

## 3. Режим «ошибка»

Приложение не просто говорит «неверно», а даёт одно конкретное действие. Проверки идут сверху
вниз: пока есть проблема уровнем выше, подсказки уровнем ниже не показываются.

| Уровень | Что замечаем | Пример подсказки |
|---|---|---|
| Кадр | рука не видна, далеко, близко, обрезана краем кадра | «Рука слишком далеко — подойди ближе», «Покажи руку целиком — она выходит за край кадра» |
| Управление | щипок не сомкнут, палец не вверх, ладонь не к камере, рука движется | «Щипок не засчитан — соедини кончики пальцев ближе», «Поверни кисть — большой палец должен смотреть вверх», «Держи руку неподвижно» |
| Путаница | kNN видит похожую букву из `confusedWith` | «Похоже на «О» — соедини кончики большого и указательного пальцев» |
| Форма буквы | нарушено условие буквы | «Согни безымянный палец», «Прижми большой палец к ладони», «Поверни ладонь к камере» |

- **Одна подсказка:** на экране всегда одна, самая важная — сначала по уровню, затем по тому, насколько сильно палец отклонился.
- **Без мигания:** подсказка появляется, только если ошибка держится 0,7 с, и сменяется не чаще раза в секунду.
- **Подсветка пальца:** палец из подсказки пульсирует на скелете. Цвет дублируется текстом и значками ✓ / ✗.
- **Статистика:** каждая показанная подсказка записывается. Из неё считаются звёзды за букву, «частые ошибки» в итогах и урок «Повтори слабые буквы».
- **Обучение:** в обучении управлению те же подсказки работают для управляющих жестов.

## 4. Архитектура

```
камера → HandLandmarker (MediaPipe, 21 точка) → проверки кадра → EMA-сглаживание
       → нормализация → признаки ─┬→ слой управления: курсор, щипок, задержка, позы → клики и команды
                                  └→ слой букв: правила + kNN → голосование → удержание 1 с
                                                                   ↘ движок подсказок → одна подсказка
```

Всё, кроме самой модели MediaPipe, — своя логика в `src/recognition/`. Это чистый TypeScript без
React, покрытый юнит-тестами на синтетических руках.

- **Нормализация** (`normalize.ts`):
  - запястье переносится в начало координат, масштаб — по отрезку запястье → основание среднего пальца;
  - кисть поворачивается так, чтобы этот отрезок смотрел вверх;
  - левая рука отражается в правую;
  - есть точное обратное преобразование — эталон можно подогнать под руку пользователя (`ghost.ts`).
- **Признаки** (`features.ts`): углы в суставах, состояние каждого пальца (прямой / полусогнут /
  согнут), расстояния между кончиками, куда смотрит ладонь, положение большого пальца.
- **Сглаживание** (`smoothing.ts`): EMA по точкам, фильтр One Euro для курсора, голосование большинством за 8 кадров, удержание позы с допуском на короткие пропадания.
- **Курсор и щипок** (`control/`):
  - центральные 70 % кадра растянуты на весь экран;
  - щипок с гистерезисом: «сомкнут» ниже 0,35, «разомкнут» выше 0,5. Клик засчитывается там, где был курсор за 100 мс до смыкания;
  - рука, вошедшая в кадр уже сжатой, не кликает;
  - после любого клика задержка «отключается», пока курсор не сдвинется. Кнопка следующего экрана под неподвижным курсором сама не нажмётся;
  - «назад» по ладони требует неподвижной руки, поэтому открытой ладонью можно спокойно водить курсором.
- **Буквы** (`letters/`):
  - приложение всегда знает, какую букву ждёт: правила проверяют только её, каждое нарушение — ошибка с кодом подсказки;
  - свой kNN (k=3, евклидово расстояние по 63 координатам, без библиотек) голосует по всем буквам; ожидаемая должна набрать 2 голоса из 3. Образцы при загрузке дополняются зеркальными, повёрнутыми на ±10° и ±15° и зашумлёнными копиями (`augment.ts`). Если рука непохожа ни на один образец, kNN не участвует, и решают правила;
  - если правила выполнены, а kNN видит похожую букву, подсказка называет палец, который дальше всего от типичной формы буквы в данных: «Похоже на «С» — согни безымянный палец»;
  - буква засчитывается, когда правила выполнены, kNN согласен и форма держится 1 с.
- **Образец буквы:** эталонный скелет буквы показывается в карточке рядом с камерой, а не поверх
  видео — наложение закрывало руку пользователя. Подгонка эталона под руку (`ghost.ts`) сохранена
  и покрыта тестами, но на экран сейчас не выводится.
- **Надёжность:**
  - GPU с откатом на CPU;
  - понятные сообщения, если камера запрещена, не найдена или занята, или модель не загрузилась;
  - сбой одного обработчика не останавливает цикл;
  - защитный экран вместо белого;
  - localStorage и озвучка необязательны — без них приложение не ломается.
- **Производительность:** цикл идёт через `requestAnimationFrame`. Скелет, курсор и кольца
  рисуются напрямую, в состояние React уходят только события: клик, буква засчитана, подсказка сменилась.

Стек: React 18, TypeScript (strict), Vite, Zustand, CSS-модули, Vitest.

## 5. Буквы и данные

### Поддерживаемые буквы

**23 статичные буквы:** А Б В Г Е Ж И К Л Н О Р С Т У Ф Х Ч Ш Ы Э Ю Я — 6 уроков. Первый урок
(В, Н, Ы) — буквы, которые камера узнаёт лучше всего на новых людях.

Не проверяются (карточка «Скоро» на карте уроков):
- **с движением** — Д, Ё, З, Й, Щ (`src/data/dynamicLetters.ts`): фото не передаёт движение;
- **исключены** — М, П (в данных ни один палец не держится одинаково у ≥ 80% людей, правил нет),
  Ц, Ъ, Ь (нет в датасетах) — `src/data/excludedLetters.ts`.

**Как показать букву**, видно на рисунке из классической таблицы дактильной азбуки — он есть на карточке
каждой буквы в уроке, в «Тренажёре» и на `/letters` (`src/data/letterPhotos/`, нарезка —
`python scripts/slice-alphabet.py`).

**Формы букв не придуманы, а выведены из данных** — и пока **не сверены с официальной таблицей**
(`verified: false`). Команда сверяет их на служебной странице `/letters` (её нет в меню): для каждой
буквы — эталон, правила и доля людей за каждым правилом, похожие буквы, точность, живая проверка
камерой. Кнопка «Экспорт overrides» выгружает отметки «сверено» в `src/data/letters.overrides.ts`.

### Данные
- [**Russian Sign Language Alphabet**](https://www.kaggle.com/datasets/kamillakabardieva/russian-sign-language-alphabet/data) (Kaggle, Kamilla Kabardieva) — ~100 фото на каждую из 25 статичных
  букв от ~60 разных людей;
- [**Russian Sign Language**](https://www.kaggle.com/datasets/mandartayade/russian-sign-language) (Kaggle, Mandar Tayade, MIT) — кадры видео одного человека, снятые
  веб-камерой спереди, как в приложении.

В репозиторий не попадают ни фото, ни видео — только координаты точек руки.

Как собираются данные:
1. `scripts/extract_landmarks.py` — MediaPipe HandLandmarker (та же модель, что в браузере) находит 21
   точку на каждом фото → `scripts/landmarks/*.json`. Тесные кропы получают рамку-отступ; со второго
   датасета перед распознаванием стирается нарисованный поверх кадра скелет. Руку нашли на 84% и 93% кадров.
2. `scripts/build-letters.ts` нормализует точки **тем же кодом, что приложение** (`normalize.ts`,
   `features.ts`), исправляет зеркальные фото (снимки с тыльной стороны и ошибки метки Left/Right —
   ориентир: видео спереди), берёт не больше 20 фото от одного человека на букву и строит:
   - эталон буквы — самый типичный образец (медоида) → `src/data/references/`;
   - образцы kNN → `src/data/samples/`;
   - черновик правил → `src/data/letters.generated.ts`: палец получает правило, только если ≥ 80%
     образцов держат его одинаково; «кончики касаются» — так же; над каждой буквой в комментарии —
     статистика, на которой основано правило;
   - похожие буквы — по матрице путаницы kNN с проверкой «на новом человеке» (все фото одного человека
     откладываются), точность выводится в отчёт.
3. Решения команды — в `src/data/letters.overrides.ts`, пересборка их не трогает.

Пересобрать:

```bash
py -3.11 -m venv scripts/.venv                                   # Python 3.11: для него есть колёса mediapipe
scripts/.venv/Scripts/python -m pip install -r scripts/requirements.txt
scripts/.venv/Scripts/python scripts/extract_landmarks.py        # фото — в scripts/data/ (в .gitignore)
npm run build:letters
```

Свои записи: на странице `/record` кнопка «Скачать точки для сборки» даёт файл в том же формате —
его кладут в `scripts/landmarks/` и запускают `npm run build:letters`. Записи с камеры приложения
считаются видом спереди и служат ориентиром наравне с видео.

Все пороги распознавания собраны в `src/recognition/thresholds.ts`.

## 6. Приватность

Бэкенда нет. Видео и координаты рук обрабатываются только в браузере и никуда не отправляются.
Нет аккаунтов, аналитики и внешних API. Прогресс хранится в localStorage этого браузера,
его можно сбросить на карте уроков.

Режим «Разговор»: видео с камеры по-прежнему не покидает устройство. Голос собеседника распознаётся
средствами браузера (Web Speech API) и может обрабатываться его сервисом — например, в Chrome речь
уходит на серверы Google. Если это неприемлемо, собеседник может написать ответ текстом.
