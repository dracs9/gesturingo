# Gesturingo

Браузерное приложение для знакомства с дактильной азбукой ASL. Маленький жест — большие возможности.

## Статус

Это **работающий фронтенд с интерактивным демо-режимом**. Распознаватели жестов, MediaPipe, ML-модели и серверная диагностика намеренно не подключены.

Пользователь открывает сайт в браузере, без установки приложения или расширений. Камера необязательна и служит только для просмотра собственной руки. Видео не записывается и не отправляется на сервер.

## Что работает

- Адаптивные экраны обучения, алфавита, прогресса и настроек.
- Шесть последовательных демо-уроков, охватывающих A–Z.
- Каталог 26 букв, поиск, фильтры и карточки с объяснениями.
- Локальные иллюстрации A–Z, объяснения и ссылка на учебный источник; для J/Z видны стрелки движения.
- Полный путь урока: знакомство → задания → пример коррекции → завершение → результат.
- Явная демо-панель: «Показать ошибку» и «Верный жест». Результат задаётся человеком, а не камерой.
- Опциональная камера с обработкой разрешений, выключением и освобождением потока.
- Демо-прогресс, история, дневная цель, серия дней и достижения в localStorage.
- Профиль без аккаунта, ведущая рука, звук, уменьшение анимаций и подтверждённый сброс данных.
- Маскот Gesturingo, собственные векторные элементы и локальные шрифты.
- Управление клавиатурой, фокус в диалогах и поддержка reduced motion.

ASL — самостоятельный язык, не «английский язык жестами». Здесь рассматривается только американская дактильная азбука. J и Z включают движение. Для исполнения и движения сверяйтесь с учебным источником: иллюстрации не заменяют полный курс ASL.

## Запуск для разработчика

Node.js 22.12+ (проверено на Node.js 24), pnpm 11.25.0.

```bash
git clone --branch codex/gesturingo-frontend https://github.com/dracs9/gesturingo.git
cd gesturingo
pnpm install --frozen-lockfile
pnpm dev
```

Откройте адрес, выведенный Vite. Установка зависимостей нужна только разработчику; конечный пользователь открывает опубликованный сайт.

```bash
pnpm build
pnpm preview
pnpm test
```

Для камеры требуется HTTPS или localhost. При отказе в разрешении урок остаётся доступен без камеры.

## Проверка демо

1. Откройте «Обучение» и начните первый урок.
2. На букве L выберите «Показать ошибку» и прочитайте конкретную подсказку.
3. Нажмите «Верный жест», затем «Следующая буква».
4. Выполните V и Y и завершите урок.
5. Убедитесь, что результат сохранён и следующий урок доступен.
6. Перезагрузите страницу: прогресс должен сохраниться.
7. В алфавите попробуйте поиск и отдельную практику буквы.
8. В настройках измените имя, цель, руку и анимации.

Демо-прогресс отражает прохождение интерфейса и не подтверждает правильность жестов или знание ASL. XP за повторно пройденную букву не начисляется повторно.

## Структура

```text
src/
  App.tsx          оболочка и главный экран
  features/        алфавит, прогресс, настройки и сценарий урока
  components.tsx   диалоги, маскот, схемы, индикаторы
  data.ts          буквы и уроки
  hooks.ts         камера, навигация, хранение, звук
  state.ts         данные прогресса и завершение сессии
  state.test.ts    восстановление данных и логика прогресса
  App.test.tsx     полные пользовательские сценарии
  hooks.test.tsx   жизненный цикл камеры
  styles.css       оформление и адаптивность
public/
  mascot/          маскот Gesturingo
  asl/             иллюстрации A–Z и sources.json с источниками
scripts/
  fetch_asl_assets.py   необязательный импорт учебных изображений
```

Технологии: React, TypeScript, Vite, Lucide, локальный Manrope. Версии зафиксированы; сборка создаёт статический каталог `dist/`.

Проверка: TypeScript и production-сборка проходят; 15 тестов покрывают все уроки, прогресс, настройки и жизненный цикл камеры. Подробности и список ручных проверок — в [docs/QA.md](docs/QA.md). Браузерная визуальная проверка пока заблокирована административной политикой инструмента предпросмотра.

## Подключение распознавания следующим этапом

В текущем задании распознавание исключено. Его будущий адаптер должен заменить ручной выбор результата в `Lesson`, сохранив интерфейс и логику урока. Ожидаемый результат: идентификатор задания, целевая буква, статус, конкретная коррекция, точки для подсветки и заполнение фиксации. Камера и урок разделены; навигация рукой появится с адаптером.

Сейчас управление осуществляется обычными кнопками. Полное соответствие условию хакатона «без мыши и клавиатуры» требует следующего этапа распознавания.

## Размещение

Приложение можно разместить на любом HTTPS-хостинге статических сайтов.

- Установка: `pnpm install --frozen-lockfile`.
- Сборка: `pnpm build`.
- Каталог публикации: `dist`.
- Навигация использует URL hash, поэтому отдельные правила перенаправления SPA не требуются.

Публичный деплой в этой ветке автоматически не создаётся. Проверенные версии браузеров и ссылка добавляются после публикации.

## Источники и материалы

- [ASL University — Fingerspelling](https://www.lifeprint.com/asl101/pages-layout/fingerspelling.htm): учебный ориентир, движения J/Z и допустимые варианты.
- Маскот создан для Gesturingo встроенным генератором изображений по предоставленному пользователем референсу; исходный дизайн маскота существовал до начала работы в этой ветке.
- Иллюстрации A–Z: wpclipart.com, через Wikimedia Commons, public domain. [Пример и лицензия](https://commons.wikimedia.org/wiki/File:Sign_language_A.svg). Исходники и лицензии каждого файла сохранены в `public/asl/sources.json`; изображения поставляются локально и не запрашиваются с внешних сайтов во время урока.
- Lucide и Manrope используются как сторонние библиотеки/шрифты; их лицензии доступны в пакетах.
