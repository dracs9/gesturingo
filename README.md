# Gesturingo — учись жестам и говори жестами

Веб-приложение, которым управляют руками через обычную веб-камеру: жесты для навигации,
обучение буквам русской дактильной азбуки с подсказками и режим «Мост» (жесты → текст и голос).
Проект ADMIT Hackathon 2026, кейс «Motion: камера вместо джойстика».

Демо: _будет добавлено после деплоя_

## Как запустить

Нужен Node.js 20.19+ или 22.13+.

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # юнит-тесты (Vitest)
npm run lint     # ESLint
npm run build    # production-сборка в dist/
```
