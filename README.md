# SignBridge

SignBridge — браузерный интерфейс для общения с помощью русского жестового языка (РЖЯ). Предполагаемый путь: жест перед камерой → распознанная фраза крупным текстом → автоматическое озвучивание. Неточный жест должен получать конкретную визуальную подсказку.

**Статус: фронтенд готов, реальный распознаватель РЖЯ не подключён.** Пользователь может написать фразу и озвучить её. Камера показывает живое видео, но само видео пока не превращается в текст. Интерфейс не притворяется, что распознал жест. Для локальной модели есть типизированная точка подключения.

Рабочая ветка: `codex/signbridge-frontend`; `main` не меняется. Предыдущая версия Gesturingo сохранена в `codex/gesturingo-frontend`.

## Путь пользователя

1. Открыть сайт в браузере: экран приветствия кратко объясняет назначение и предлагает одну основную кнопку «Начать общение».
2. После нажатия открывается экран разговора и запрашивается видеокамера. Видео не записывается и не отправляется на сервер.
3. На экране разговора видны камера, состояние жеста, крупная последняя фраза, кнопка повторного озвучивания и короткая история. Озвучивание новых фраз включено по умолчанию, его можно выключить одним нажатием.
4. Если камера недоступна или модель ещё не подключена, можно написать фразу и озвучить её. Это запасной путь, а не выполнение требования хакатона о распознавании движений.
5. Кнопка завершения останавливает камеру и звук, после чего показывает число сообщений и последнюю фразу. Новый разговор начинается без старой истории.

В интерфейсе нет боковой панели, словаря, профиля, настроек, ручных демо-кнопок и лишней навигации. На телефоне камера и текст располагаются последовательно. Видеопоток отпускается при завершении, скрытии вкладки и закрытии приложения.

## Запуск

Разработчику нужны Node.js 22.12+ и pnpm 11.25.0:

```bash
git clone --branch codex/signbridge-frontend https://github.com/dracs9/gesturingo.git
cd gesturingo
pnpm install --frozen-lockfile
pnpm dev
```

Откройте адрес, показанный Vite, обычно `http://127.0.0.1:5173/`. Исходный `index.html` не предназначен для запуска через `file://`. Пользователю опубликованного сайта устанавливать ничего не нужно. Для камеры требуется HTTPS или localhost.

```bash
pnpm test
pnpm build
pnpm preview
pnpm format:check
```

## Подключение распознавания

`src/signbridge/adapter.ts` принимает 21 точку кисти, кандидатов классов, состояние (`tracking`, `almost`, `recognized`, `uncertain`), конкретную коррекцию и идентификатор события. Интерфейс отображает скелет и стрелку поверх видео с учётом зеркала, добавляет принятую фразу в историю и озвучивает её. Повторные кадры одного `eventId` не создают повторных сообщений.

Чтобы кандидат мог вызвать сообщение из камеры, его класс должен быть документирован, иметь `verified: true`, пройти порог уверенности и отрыв от конкурентов. Красный скелет и точная подсказка показываются только для валидной ошибки с достоверной целью. Неоднозначный жест остаётся нейтральным. Встроенные пять названий фраз — непроверенные тестовые фикстуры, не распознаваемый словарь РЖЯ.

Фронтенд проверяет и отображает результат модели, но **не определяет ошибку геометрии самостоятельно**. Профили жестов, сравнение движения и реальная калибровка остаются задачей распознавателя. Расстояние в сантиметрах по некалиброванной камере не выводится. Подробный контракт: [docs/RECOGNITION.md](docs/RECOGNITION.md).

Источники для следующего этапа: [Slovo — жесты-слова](https://github.com/ai-forever/slovo) и [Bukva — русская дактильная азбука](https://github.com/ai-forever/bukva). Их модели, веса и видео в эту ветку не включены. Для первой версии общения выбрать 3–5 подтверждённых классов и сопоставить их с фразами после просмотра примеров и проверки с пользователем РЖЯ.

## Соответствие кейсу ADMIT

| Требование               | Сейчас                                                   | Следующий шаг                                   |
| ------------------------ | -------------------------------------------------------- | ----------------------------------------------- |
| Открытие без установки   | Готово: статический сайт                                 | Опубликовать на HTTPS                           |
| Распознавание в браузере | Камера и интерфейс адаптера готовы                       | Подключить и проверить локальную модель         |
| Три жеста, три действия  | Не выполнено: текстовый запасной путь                    | Проверить три жеста и три различимых результата |
| Понятная обратная связь  | Скелет, статусы и текст подключаются к событиям адаптера | Проверить на реальном видео                     |
| Режим «ошибка»           | Красная подсветка, суставы, стрелка, конкретный текст    | Реальная диагностика по проверенным профилям    |
| Сценарий до результата   | Интерфейс от приветствия до итога работает               | Пройти весь путь жестами                        |

**До подключения распознавания это не готовый конкурсный MVP.** Тесты с искусственными событиями проверяют интерфейс, а не качество модели.

## Структура

```text
src/signbridge/
  SignBridgeApp.tsx  приветствие → общение → итог
  adapter.ts        точка подключения модели и жизненный цикл
  model.ts          словарь, валидация результата, тестовые фикстуры
  camera.ts         разрешения и поток камеры
  speech.ts         браузерное озвучивание
  Skeleton.tsx      кисти, суставы и стрелка
  styles.css        адаптивный дизайн
  *.test.ts(x)      сценарии и проверки границ
```

React, TypeScript и Vite создают статический `dist/`. Публикация: `pnpm install --frozen-lockfile`, `pnpm build`, загрузка `dist` на HTTPS-хостинг. Публичный деплой не создан. Проверки и ограничения — в [docs/QA.md](docs/QA.md).

История хакатона: React/Vite, камера и первоначальный маскот пришли из версии Gesturingo, созданной во время того же хакатона. После смены направления интерфейс переделан в этой ветке; маскот и материалы ASL не используются. Даты работы отражены в коммитах. Название команды и ссылка на деплой добавляются перед сдачей.
