# SignBridge

Браузерное пространство для общения с помощью русского жестового языка (РЖЯ). Целевой сценарий: проверенный жест → распознанное намерение → фраза в диалоге → озвучивание; неточный жест → конкретная визуальная подсказка.

**Статус этой ветки: работающий фронтенд, распознавание ещё не подключено.** Камера показывает настоящий видеопоток; скелет, классификация и коррекции демонстрируются отдельно, через явно обозначенную ручную панель. Приложение не заявляет универсальный перевод РЖЯ.

Рабочая ветка: `codex/signbridge-frontend`. `main` не изменяется. Предыдущая версия Gesturingo сохранена в `codex/gesturingo-frontend`.

## Что работает

- Адаптивные экраны общения, словаря, итогов сессии и настроек.
- Камера без записи и отправки видео: включение, выключение, переключение фронтальной/задней камеры, обработка отказа в разрешении.
- Зелёный/красный/нейтральный скелет, выделение суставов, стрелка к целевому положению и конкретная инструкция.
- Пять примеров коррекции: высота кисти, форма пальца, поворот ладони, направление движения, длительность.
- Пять **макетов фраз**: «Здравствуйте», «Мне нужна помощь», «Спасибо», «Да», «Нет». Их соответствие классам Slovo и исполнение жестов ещё нужно верифицировать. Синтетический демо-скелет не является образцом РЖЯ.
- Двусторонний текстовый диалог, повторное озвучивание, автоматический TTS по выбору пользователя, экспорт разговора в TXT.
- Субтитры речи собеседника при поддержке SpeechRecognition, с отдельным согласием на микрофон и возможную внешнюю обработку аудио.
- Итоги: число сообщений и ответов, длительность, число исправлений в демо.
- Настройки голоса, зеркального просмотра, уменьшения анимаций и сохранения диалога.
- Рыжий кот-маскот, локальные шрифты, клавиатурная навигация, фокус в диалогах, подписи состояний помимо цвета.
- Типизированный интерфейс будущего распознавателя: проверка уверенности, защита от повторной отправки одного события, очистка ресурсов и проекция двух кистей поверх видео.

Посетителю опубликованного сайта ничего устанавливать не нужно. Установка зависимостей ниже предназначена только разработчику.

## Запуск

Node.js 22.12+ (проверено на Node.js 24), pnpm 11.25.0.

```bash
git clone --branch codex/signbridge-frontend https://github.com/dracs9/gesturingo.git
cd gesturingo
pnpm install --frozen-lockfile
pnpm dev
```

Откройте HTTP-адрес, который выведет Vite, обычно `http://127.0.0.1:5173/`. **Не открывайте исходный `index.html` через `file://`**: приложение требует запуска сервера или публикации собранного `dist/`.

```bash
pnpm test
pnpm build
pnpm preview
pnpm format:check
```

Камера требует HTTPS или localhost. На телефоне используйте опубликованный HTTPS-сайт: обычный HTTP-адрес компьютера в локальной сети может не дать доступ к камере.

## Как пройти демо

1. На экране «Общение» нажмите «Попробовать демо».
2. Выберите фразу и пример коррекции.
3. Нажмите «Показать ошибку»: скелет станет красным, появятся выделенные суставы, инструкция и стрелка. Для ошибки длительности показывается инструкция удержания без стрелки.
4. Нажмите «Исправить жест»: скелет станет зелёным, фраза добавится в диалог с пометкой «Демо».
5. Выберите ещё две фразы и повторите сценарий. Это проверка интерфейса, а не три реально распознанных жеста.
6. Собеседник может написать ответ. При наличии TTS нажмите кнопку озвучивания сообщения; автоматическое озвучивание включается в настройках.
7. Нажмите «Завершить»: камера/микрофон/озвучивание останавливаются, появляются итоги. Диалог остаётся доступен.

Кнопка с вопросительным знаком демонстрирует неоднозначный результат: корректирующая стрелка скрывается, сообщение не отправляется.

## Режим «ошибка»

Фронтенд принимает от будущей модели ранжированные кандидаты и конкретную коррекцию. Если ближайший жест достаточно убедителен и отличается от второго кандидата, показываются красный скелет, проблемные суставы и мини-гайд, например: «Подними ладонь к отметке и удерживай положение 0,5 с».

Текущие пороги `score ≥ 0.65` и разница `≥ 0.12` — предварительные настройки интерфейса, не результат оценки модели. Их нужно подобрать на отдельной проверочной выборке. Неоднозначное распознавание остаётся нейтральным. Неполный/некорректный скелет и неверифицированный класс камеры не могут добавить фразу в диалог.

Обычная камера без измеренного масштаба не позволяет достоверно советовать перемещение в сантиметрах. Поэтому интерфейс показывает целевую область. Автоматическая диагностика формы/траектории и настоящая калибровка должны быть реализованы в адаптере; нынешняя подготовка камеры — ручная проверка освещения и кадрирования.

Контракт и план интеграции: [docs/RECOGNITION.md](docs/RECOGNITION.md).

## Источники РЖЯ

- [ai-forever/Slovo](https://github.com/ai-forever/slovo): источник жестов-слов, RGB-видеопримеров и подготовленных landmarks рук. Основной кандидат для ограниченного словаря коммуникации.
- [ai-forever/Bukva](https://github.com/ai-forever/bukva): русская дактильная азбука, включая динамические знаки. Возможный отдельный режим букв.

Ссылки на датасеты не означают интеграцию модели. Данные, веса и видео из этих репозиториев в эту ветку не скачивались. Предобученные видеомодели требуют временной последовательности кадров; их нельзя напрямую подменить сравнением одной статической кисти. Для конкретных подсказок потребуется отдельная логика диагностики.

При добавлении примеров сохранить точный класс, идентификаторы роликов, условия использования и атрибуцию из соответствующего источника. Документированные примеры проверить с компетентным пользователем РЖЯ; название выходной фразы и класс жеста могут различаться.

До подключения модели это **не полный конкурсный MVP**. Разные фразы в демо не являются доказательством выполнения требования «3 движения — 3 действия». Команде нужно явно связать три распознанных жеста с тремя результатами и проверить трактовку условия для коммуникационного сценария.

## Данные и возможности браузера

Камера запрашивает только видео. При паузе, уходе с экрана общения, скрытии вкладки и закрытии приложения поток освобождается. Распознаватель по умолчанию отсутствует. Видеозаписи и серверных запросов приложения нет; шрифты и маскот локальные.

История по умолчанию хранится в памяти текущей вкладки. Сохранение последних 100 сообщений в localStorage включается отдельно; настройки сохраняются локально. Экспорт скачивает текстовый файл на устройство.

TTS зависит от голосов устройства. Автоматический выбор предпочитает локальный голос нужного языка, но выбранный голос может использовать сетевой сервис. Субтитры поддерживаются не всеми браузерами и могут передавать **аудио** сервису браузера. Это отдельный механизм, не передача видеопотока. При озвучивании микрофон субтитров останавливается, чтобы приложение не записывало собственный голос.

Справка: [SpeechSynthesis](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis), [SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition).

## Структура и размещение

```text
src/
  main.tsx                    точка входа
  signbridge/
    SignBridgeApp.tsx          экраны и сценарий общения
    model.ts                  словарь, события, фильтрация и демо
    adapter.ts                интерфейс и жизненный цикл распознавателя
    camera.ts                 камера и разрешения
    speech.ts                 TTS и субтитры
    Skeleton.tsx              кисти, суставы и стрелка коррекции
    styles.css                адаптивный дизайн
    *.test.ts(x)              сценарии и границы интеграции
  shared/Modal.tsx            доступные диалоги
public/
  mascot/                    маскот
  favicon.svg                знак SignBridge
```

React, TypeScript, Vite, Lucide, Manrope. Версии зафиксированы в lockfile. Сборка `pnpm build` создаёт статический `dist/`. Для хостинга: установка `pnpm install --frozen-lockfile`, сборка `pnpm build`, публикация `dist` на HTTPS. Навигация через URL hash не требует серверных перенаправлений SPA. Публичный деплой в этой ветке ещё не создан.

Результаты проверок и оставшиеся ручные проверки: [docs/QA.md](docs/QA.md).

## Материалы и история

Маскот создан ранее в этом чате генератором изображений по референсу пользователя. Сторонние библиотеки и шрифты сохраняют свои лицензии в пакетах. Материалы ASL предыдущей концепции удалены из этой ветки, чтобы не смешивать языки.

База React/Vite, компонент диалога, камера и маскот перенесены из версии Gesturingo, созданной во время этого же хакатона. Новая логика SignBridge отражена отдельными коммитами. Подготовленные ранее идея, ТЗ и маскот указаны как исходные материалы; даты разработки не подменяются. Название зарегистрированной команды и ссылка на деплой добавляются перед конкурсной сдачей.
